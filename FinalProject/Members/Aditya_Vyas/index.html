About the Simulation

This dashboard visualizes the output of the RumorGuard C++ backend. It generates a Barabási–Albert scale-free network with preferential attachment, computes Brandes' betweenness centrality, and applies a stochastic SIR contagion model across 20 trials.

The Greedy Influence strategy achieves the strongest containment by selecting nodes that maximize marginal susceptibility reduction using a max-heap approximation.
